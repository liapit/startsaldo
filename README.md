# StartSaldo

CREATE A PREMIUM SWISS ACCOUNTING WEBSITE

Build a complete, polished, responsive one-page website for a small Swiss accounting business run personally by two professionals.

The company specialises in:

Finanzbuchhaltung

Lohnbuchhaltung

The primary target customers are Swiss SMEs, GmbHs, AGs, startups and self-employed professionals.

The visual impression must be:

precise, trustworthy, personal, calm, premium, modern and Swiss.

This should NOT look like:

a startup SaaS landing page

a flashy marketing agency

a traditional old-fashioned Treuhand website

a generic corporate template

a bank

a website filled with stock photography

The emotional reaction should be:

“These are competent, organised people whom I would feel comfortable trusting with my company's finances and payroll.”

1. CORE DESIGN IDEA

The design should combine:

Swiss visual precision
+
modern editorial web design
+
personal boutique service

Think:

lots of whitespace

disciplined alignment

oversized but elegant headlines

few colours

warm off-white backgrounds

dark green / deep petrol as the primary brand colour

subtle light-sage sections

large rounded cards

extremely clean typography

real photos of the two founders

minimal icons

no visual clutter

no unnecessary decorative graphics

The website should feel expensive because it is restrained.

Do not try to make every section visually different.

Consistency and order are more important than visual novelty.

“Die beste Buchhaltung der Schweiz.”

Instead use language like:

Klare Abläufe. Persönliche Betreuung. Verlässliche Buchhaltung.

36. CONTENT DENSITY

Avoid long text walls.

Most paragraphs should be:

2–4 lines on desktop.

Use maximum paragraph width:

approximately 600px–680px.

Long biographies are the exception.

Every section should communicate one main idea.

37. GRID SYSTEM

Desktop:

12-column layout.

Use consistent alignment throughout.

Typical gaps:

24px

Large layout gap:

48px–64px.

Do not randomly change container widths from section to section.

All major headings should align to the same page grid.

This creates the Swiss precision feeling.

39. VISUAL HIERARCHY RULE

Each section should contain approximately:

1 small eyebrow

1 strong headline

1 supporting statement

1 main visual/content component

Do not place multiple competing headlines in one section.

40. ACCOUNTING-SPECIFIC TRUST SIGNALS

Trust should come from the following:

Real people

Clear scope

Explain exactly what they do.

Professional restraint

Avoid flashy claims.

Precise language

Avoid vague statements.

unless such certification genuinely exists.

Two identifiable professionals.

Personal, precise, structured service.

Arrange an introductory conversation.
